# Aplicación — Event Furniture

Interfaz de asesor construida con React + Vite + Tailwind.

Consume la API por HTTP usando VITE_API_URL (por defecto
http://localhost:8000/api/v1). Implementa inicio de sesión,
catálogo de artículos y creación de alquileres.

Se construye con Node 22 (app.Dockerfile) y se sirve con Nginx
en el puerto 8081.
