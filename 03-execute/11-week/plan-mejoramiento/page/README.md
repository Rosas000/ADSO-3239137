# Sitio público — Event Furniture

Sitio estático que presenta el producto: qué es, qué problema resuelve,
las cinco categorías y las funcionalidades principales.

No consume la API y no requiere JavaScript para mostrar contenido.
Se sirve con Nginx desde la imagen page.Dockerfile en el puerto 8080.
El enlace de acceso a la aplicación apunta a http://localhost:8081.
